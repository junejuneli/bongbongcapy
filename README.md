> **敲好运**（谐音“超好运”）是一款治愈系卡皮巴拉键盘陪伴游戏，让每一次敲击都能积攒好运。

<img src="public/images/主宣传图1232.jpg" alt="敲好运主宣传图" width="100%" style="border-radius: 12px; margin: 20px 0;"/>

## ✨ 游戏特色

- 🐹 **超萌水豚伙伴**：伴随键盘节奏互动陪伴
- 💝 **功德许愿系统**：在荷花池积攒功德许下心愿
- 👗 **丰富换装系统**：收集奇珍服装，打造独一无二的水豚
- ☕ **完美工作伙伴**：边工作边养成，赶走摸鱼焦虑
- 🌸 **治愈系体验**：偶尔卖萌偷懒，让工作更有温度

## 🌐 在线体验

- **主站入口**： [capy.ybxqk.cn](https://capy.ybxqk.cn)
- **Windows**：支持 Windows 10/11
- **macOS**：支持 macOS 12+
- **Linux**：版本筹备中

## 🎯 核心亮点

### 🌍 国际化支持
- 🇨🇳 **中文**：完整的简体中文体验
- 🇺🇸 **English**：完整的英文本地化
- 🇯🇵 **日本語**：完善的日语支持

### 📊 数据分析
- **Umami 事件追踪**：洞察用户行为
- **实时统计**：下载与交互即时掌握
- **隐私友好**：不收集个人隐私数据

### 🖱️ 交互体验
- **响应式设计**：覆盖桌面、平板与移动端
- **流畅动画**：Framer Motion 带来丝滑体验
- **智能导航**：锚点定位与平滑滚动

### 🎮 游戏集成
- **实时预览**：在线体验核心玩法
- **服装展示**：3D 旋转查看全部装扮
- **下载管理**：自动识别系统推荐版本
